# 完形填空 · 老师方法库

> 蒸馏自《语法完形训练第二阶段——完形填空知识综述》《一轮复习——完形填空》原声课。

## 定位与战略

- 完形本质是**考词的题目**：动词、名词、形容词副词三大块，连词介词极少（"一篇文章里可能有一道题就了不起了"）。
- 完形重点永远只考**名词和动词**。要求：所有名词题和动词题是"不能错"的题。形容词副词相对简单，连词介词是死知识。
- 难度预判：一篇完形**名词题多→简单**（名词是什么就是什么）；**动词题多→难度高**（动作牵扯面广，理解容易有偏差）。
- 36篇训练分三阶段：1-6套认考点学方法；7-24套积累操作经验；最后12套综合练。
- 做错完形只有三种根源：①对词的理解有偏差；②对用法不熟悉；③把词错误引申成另一个含义。

## 总原则：找对应，不翻译

- 最根本依据："你要知道这道题目需要填什么词，而**这个词和文章里面要有一些已知信息的对应**——这是我们判断这个题目最根本的依据。"
- 明确反对翻译法：翻译可能不准确，判断就会受影响。**跳过翻译这个层面**，直接看空格要填的词和文中对应词的关系。不要求把整句翻译成靠谱中文才能做题——需要注意的永远只有句子里的**局部**。
- 觉得完形乱、没头绪，是因为没先定性："这道题是动词题，我就要考虑动词对应的内容；是名词题，就考虑名词需要我考虑的事。"——**你面对的是什么题，你就要去想什么样的事。**

## 动笔前先定性

- "99.99%的完形填空，四个选项词性是一模一样的。"不知道填什么，看选项就OK了。
- 拿不准用"能确定的选项"反推：fixed/enormous/complicated/close 中 enormous、complicated 只能是形容词 → 必是形容词题。
- 满打满算只考六件事：名词、动词、形容词、副词、连词、介词。解题思路一句话——**"什么样的词，我该怎么样去应对它"**。

## 名词题规则

1. **名词一定要有具体的对应内容**：填什么名词，这段话里就必须有和它相关的内容。
 - 标志性比方：填 elephant → 文章里必须有动物园、其他动物、giant ears、long nose；看到的是 school、classmates、books，就不可能是大象。
2. **抽象名词**（happiness/success/confidence/determination 这类看不见摸不着的）：发挥**概括**作用，一定要有具体内容的对应——
 - happiness ← 前文 laughter；determination ← 有目标有终点；confidence ← believe myself、not afraid；honesty ← 没说谎、拾金不昧；文章写帮别人、timely help → generosity 或 kindness。
3. **具体名词**（人物、事物）：在文章里**复现**，是推进故事的线索。填 rose → 玫瑰不止出现一次；填 friend → friend 反复出现还可能配 friendship。
4. **复现规则的边界**：复现思路只适用于名词题、以具体名词为主。动词题不能用复现——故事靠不同动作推进，反复做同一个动作就是原地踏步；形容词同理，反复用同一个形容词文章就写得很差。
5. **词义使用条件**：mood=喜怒哀乐；relationship 至少两者以上；performance 得先"做某件事"；解决的问题是 problem 不是 question（question 需要 answer）；explanation 必须有人提问或自问自答。
6. **总扩句里的名词**要和后面内容形成对应：后面给方法→solution；聊未来→prediction；讲怎么用→application；回答上一段的问题→explanation。

## 动词题规则

1. **盯住动作的发出者和动作的对象**——这动作谁做的？对谁做的？
2. **已知动词与未知动词要形成连续、合理的动作顺序**（旁边有没有连续动作——一串连续动作，还是转折，还是因果）。
3. **逐项荒谬化反问**：把选项代入场景追问合理性——"你能够踢他的门吗？这是邮递员该对门做的动作吗？""138个人都在思念同一件事，这个多诡异啊。"
4. **词的使用条件**：
 - avoid 后面往往加"问题/异常的事"，不可能接正常的事；
 - repair 的使用条件——先得出了故障，没坏你修什么；
 - absorb=吸收=融为一体，"我吸收知识，你和知识就融为了一体"，所以 absorb 又考"理解"；
 - consume=吃；serve food=把食物给别人；purchase 每次都和钱有关；secure=确保安全/确认获得（secure my position）。
5. **正负态度配对**：前面需要负态度，才能和后面 fortunately 的正态度形成对应——"这就是动作的内在逻辑"。
6. **动词短语不需要背，看一个记一个**。动词短语=动词和介词的组合，背不完；考试就遇到4个还不一定是你不认识的。make up 四义：弥补/构成/虚构/化妆（最后这个记不记无所谓）。**普适备考铁律：任何一科，"一大堆东西全背下来最后就从里面考某一个"这种事永远不要干——省下来的时间干别的，能把那分翻着倍地拿回来。**

## 形容词副词题规则

1. 形容词描述**人物或事物的性质**；副词描述**动作的状态**，还可能在句子里发挥**逻辑作用**。
2. 形容词体现正/负/中性态度，**必须与文章统一**——前文 happier 是正态度，选项偏负（complicated=复杂，给人难的感觉）就矛盾。
3. 副词三步排除定型：①正负态度？②描述动作的状态？③都不是→一定和**逻辑**有关（especially=递进，occasionally/rarely=频率，reasonably=正确性）。
4. 渐变词 gradually："文章里没有渐变过程绝对不要选它"——渐变不是像翻硬币那样的直接变化，需要时间投入。
5. 结构意识：far from + 形容词 = "离……还差得很远"（far from common = 不常见 = 独特）；选项对应文中 orange/yellow sticker → colorful。

## 连词介词题

- 每个选项每个词的用法是固定的，不随语境变化。逐词排除：until=直到（后面加结果/条件）；since=自从/因为；immediately=强调两动作间隔短；before=描述**顺序**（"在它有时间反应以前"）。
- 逻辑词校验：but、fortunately、while 锁死前后态度，选项必须自洽。

## 中心线索

- 文章开头/结尾出现概括性、理论性、习语性的语句，可能就是文章中心（如 "Laughter is the best medicine"）。**所有情节、所有题目的选择都要往这个中心上靠**。

## 词汇硬要求

- 讲完一篇，选项里40个词必须全部认识，"没商量"——不管你怎么记。
- 文章里的其他生词不要求全查背："我给你赌100块钱，明年6月8号高考里面没它。"
- 按使用条件记词："你知道它的中文含义是一方面，但你得知道它什么时候能用。"

## 做题流程

1. 先通读，把握故事线和作者态度，抓中心线索；
2. 逐题定性（看选项定词性）；
3. 按词性套对应线索系统（名词找对应/动词看逻辑/形容词看态度/连词查用法）；
4. 选完整篇连读验逻辑；
5. 错题自检三根源（词义？用法？错误引申？）。
