# 讲题实录 · 老师方法库（带刷题模式）

> 蒸馏自《高考英语全程课新模拟题27》系列 90 期逐题讲解实录（视频平台 AI字幕转写稿，2026-11 采集）。这是"拿着真卷子现场讲"的过程记录——方法规则的来源见各题型文件，本文件记录**讲题的节奏、话术和真题示范**。

## 各题型讲题节奏（三批实录交叉验证一致）

### 语法填空
- 开场先评难度："这套语法填空整体不算难""只有一道题是用来拉开高分和中档分数的。"
- 单题四步：**报题号定性 → 拆句找谓语 → 谓语三查/非谓语二选 → 口诀式落地**。
 - 开口话术："56题，各位一上来就看到了，这是一个没有提示的空格""给了我们一个动词 float"。
 - 拆句："逗号后面没有关系词没有连词，它就应该是非谓语了呗。"
 - 谓语三查："动作时间—主动被动—主语单复数。过去到现在，现在完成时，被动，主语单数，那不就是 has been done 吗。"
 - 非谓语："后面应该有名词……那合理的就只能是被动""努力当然有一个目标……描述目的的 to do"。
 - 收尾分档："除了偏题，剩下的九道各位一道都不应该错。""非谓语六个形式必须都得知道。"
- 从句三步："主句从句的谓语挨个画出来"→ 看缺不缺名词 → 主句完整+从句缺人/物 → that/who、that/which；都完整 → where/when/why/that → 再不成立 → 逻辑连词（and/or/but）。

### 完形填空
- 先带一遍故事线和情感基调（"讲的就是走出舒适区"），再逐题。
- 逐题四对应律：**名词找对应内容；动词看连续动作与顺序；形容词判感情色彩；副词看逻辑**。
- 话术："X题需要你填的是一个名词，这个名词有对应内容""前面是负态度……能选的就只有B""后面是下定决心遵循，前面就应该是不遵循"。
- 情感曲线意识："前面两段全是负态度，到倒数第二段该转正了，由负到正总得有个契机。"
- 收口："每道题都应该有自己的对应……和整句翻译没有那么直接的关联。"

### 阅读理解（A/B/C/D 分型）
- 篇章先行定性："这明显是一个应用文，里面有小标题""研究类的说明文，第一段最后一句就告诉你研究结论"。
- **A 应用文**：出处题当主旨题做（"考虑文体、写作对象、谁是读者"）；细节题对标题定位并动手算数。
- **B 人物记叙**：先立人物身份，正面人物→评价题先排负态度词；"每一道细节题都会有重要信息的标志——but 的后面、两段的段首句、我直截了当告诉你这件事是 key"。
- **C 科研说明**："三道题的文章永远要速战速决"——只精读第一段研究结论，其余全做验证："你就怼着这个结论选"；带数字的选项先核（"有明确的数字，很容易呼应"）。
- **D 议论文/方法论**："所有的解题技巧不能凌驾在题目要求以上……题目怎么问，你就怎么答。"
- 总原则："我不需要你把句子看明白，只需要你看明白选项跟句子怎么对应起来。""看到什么选什么，这就是客观题对你的要求。"

### 七选五
- 动笔前先给**七个选项标属性**：正负态度、功能（问题/作用/建议/因果）、格式（小标题须是祈使句）、时态分组。
- "选择范围越小题目越容易，二选一最容易。"
- 填空验证：指代（this/they）、复现词、逻辑（"你说不要干什么，后面就得说你要干什么，由负到正"）。
- 终杀排错："任何一个相邻句里都没有的内容，就不能选""读起来舒服但内容上没关联"必错。
- "E 在需要负态度的位置没 PK 过 G，其他地方也就不需要它了。"

### 应用文
- 先定结构："投稿应该有稿件格式，前面有总括段……最后有总结段"；三要点篇幅均衡。
- 要点公式：建议=建议本身+原因/结果；申请=担任什么+个人优势+正面结果。
- 写完做**压缩示范**："删掉了一半的内容，但是要点一个都没有少。"

## 例题实录精选（题目要素 → 思路链 → 收尾）

1. **非谓语 to be done**（山东卷 polish 题）：原文 more details still __(polish)。"逗号无连词→非谓语；后无名词→被动；still 表示接下来还要这么做——done 描述发生过的不行，要用表示目的、预期的被动非谓语，to be done。"
2. **冠词 an**（"额外300万元补助"）：主句已成立不能再填关系词→空格只管名词短语→冠词。"计量单位前用 an：一个100元的 reward、八个人的 group、800米的 distance。"
3. **关系词 which**（成都 pilot program, ___ begins this autumn）："主句不缺名词→主句完整；begin 没主语→从句不完整；前面是物→that/which。若写 and，两谓语共用主语——开始的是项目，不是成都，句意不合理→不行。"
4. **现在完成被动**（So far…initiatives ___(launch)）："so far 过去到现在→现在完成时；开展计划→被动；主语复数→have been launched。三个环节都判断出来，答案就有了。"
5. **完形 betrayal**（"对我来说是种背叛"）：失望+regret+走完赛=失败感→"负态度只有 C 和 D，压力和前文没关系→betrayal，背叛了我给自己定的高标准。"
6. **完形 without exception**：without 短语补充 follow 的状态——not mercy、not delay（两动作间隔短）、not regret→"没有例外=强制自己严格执行"。附辨析：confirm 是"不确定→确定"的过程；question 带负面看法，resist 是心里不愿意。
7. **职业评价题**（2021新高考I卷 B篇）：boring/dangerous 与正面人物矛盾、well-paid 无依据→demanding；回文验证："第三段段首 A lot of skills are needed、第四段段首 requires plenty of practice——**段首句就是答案位置**。"
8. **词义猜测 intermittent**（朝阳 C篇）：回研究结论 "small electrical signal"→"哪个选项能表示 small"；旁证 "continuous stimulation had no effect——持续的无效，间歇的有效"；constant/frequent 都是"多"、random 是随意→periodic。
9. **七选五小标题**（2026新高考II卷）："总分结构必挖一个标题""其他标题都是祈使句→答案在 B、C 里二选一"；段落讲"孩子看到你怎样就怎样"→model；"选了 C，B 大概率就作废了。"
10. **完形抽象名词概括**（indication/evidence 双题）："要是它不难，就会是一个你不在乎的什么？不是问题、错误、结论，是一个表现（indication）；'这件事痛苦'这一事实就是你在做有意义的事的证明（evidence）——这俩题考法一模一样：**对前后内容做概括**。"
11. **逻辑副词 contradict**（广州一模 C31）："interestingly 是逗号独立的副词，往往发挥逻辑作用；前面 most commonly，后面 the lowest，最常用对最少用，两相矛盾——选 B，contradict a common assumption。"
12. **标题题正负判断**："结尾说 Both global warming and global diming prove fatal。both and 说明二者同性质，warming 是坏事，diming 就不是好事；排除正态度的 C，选 D（mask 掩盖）。"

## 细颗粒技巧与易错点（实录中反复出现）

- **考点排他**："一套卷里不可能有两个名词复数考点""非谓语被动一篇文章最多考一回"——考点撞车必有玄机。
- **删元法**：冒号、破折号、插入语"当它们不存在"，"俩逗号之间直接砍掉"。
- 三者并列 "A, B, and C" 可跨词性：仨名词、仨谓语、仨非谓语、仨句子皆可；"俩句子拿逗号连着，只有一种可能，写 and"。
- "to do and do" 第二个 to 可省，"隔得远建议写全，结构更直观"。
- 名词+ly=形容词一套：daily/weekly/monthly/yearly。不规则动词"判断对了还得写对"（run—is run）。
- 无提示空前有介词且被逗号隔开："先看它和主句有没有关系，没关系就归从句。"
- 疑问词+to do = "疑问词+情态动词句子"：how to thank = how I can thank。
- 过去完成时的反向限制："不是说有先后顺序就一定要用过去完成"——and 连的紧密连续动作不用；真用要看 by+过去时间这种大标志。
- 冠词 A/the 口诀："拿'一个或某个'的意思往里套，说得通就是 a。"
- 完形词辨析：instead="一边否定一边肯定"；look up="事情好转，情节转折常客"；outweigh="正压过负"；nail（钉住→搞定）、tend to sb、seed（播种→孕育）。
- 阅读秒排除："学校项目的影响一定是好的，short-lived 这种直接扔——这种题目文章看不看已经无所谓了。"（先验判断，但永远服从题干）
- 七选五："不破不立——有否定必带出肯定"；"段首总括句选涵盖面最广的"；"负态度选项全文往往只有一处需要它"。
- 应用文表达多样性："不是换高级词，是几个要点有不一样的表述方式"——正反表述、总分展开、排位与原因拆开各用一次。"写作课里重要的不是你不知道的，是你觉得有用的。"
- 命题学彩蛋（讲评卷子时会点破）："连着三个 C，对学生心理有影响，命题应避免"——正确答案字母排布是散开的。
