# 学习规划与提分策略 · 老师方法库

> 蒸馏自《高考英语全程课小课堂二：词汇应该怎么背》《小课堂三：提分应该怎么做》（0-59/60-99/100-129 分层课）《小课堂五：作文应该怎么办》《小课堂六：高一高二干什么》（视频平台 AI字幕转写稿），2026-11 新增。

## 全年三档次目标（先定档，再谈方法）

- "**想及格，你要搞定的就是词汇；想拿到120，你要学会做客观题；想拿到140，你要学会写作文。**"
- 三件事按序："第一件事叫词汇，第二件事叫客观题的解题思路和解题经验，第三件事就是写作。"

## 硬时间线

- **词汇**：12月31日前搞定 → 110+；暑假搞定 → 冲120/130+；春节才搞定 → 最多及格；春季还在看单词 → 及不了格（详见词汇方法库）。
- **写作**：高三 1 月起写作升级为重点，"从每年的高三1月份开始，每个同学都要把写作当做重要的事情来对待"；1月前主攻客观题。
- 客观题解题思路："暑假班和秋季班里面给各位重点讲的……需要各位结合课程做到**滚瓜烂熟**"——这是错题分析能成立的前提。

## 高一高二该干什么

- 英语学习轨迹："小学=基本词句认知 → 初中=基本的语言规则 → 高中=基本的**理解运用** → 大学才真正接触语言本身。"
- 初高中断层的原因："中考靠死记硬背、短期突击，英语是可以突上来的，因为它要求的是基本规则；到了高中要求理解运用——你知道它前后的来龙去脉、它在这发挥什么作用，还要学会运用到写作口语里。**高一特别是高一下学期开始跟不上，就是因为对语言的要求变了。**"
- 初三就来听课？"并没有直接的帮助——高考考的和中考不一样。"从高一接触比较合理。
- 高一高二两件事：①把课本内词汇掌握好；②"想让高三更有效率、走得比别人快，高二的时候核心词汇就应该完全把握。"
- 警示案例的讲法："有同学说我现在只能考19分、27分、36分——到高三还面对这样的成绩是非常不合理的，因为高一高二该做的事情你没有做。"

## 提分分层（分档开方，各阶段向后兼容）

- **演进逻辑**：第一类同学"别做题，做题就是浪费"→ 第二类"学会做**所有题**"→ 第三类"只做你的**错题**"。要求面对的题量在变少，"变少的背后是你要对自己足够了解"。
- **0-59**：只干词汇这一件事（见词汇方法库）。
- **60-99**：一轮复习六个月重点一件事——**客观题解题思路**。量化指标："以往完形错12个，现在要求错4个；语法填空错6个，现在要求错得更少；七选五一做就错4个，现在只能错1个。"
 - 病灶诊断："面对英语就俩字叫翻译，不行就换俩字叫语感——太可怕了。""其他学科都有解题思路，语言类学科更要有。"
 - 理论根基："**解题就是命题的反操作**"——知道结是怎么打的，就知道怎么解开。
 - 方法论：解题思路（可数、几页纸就讲完）→ 用思路解题 → 积累经验（"做对了是思路有效，做错了是思路需要补充还是应用不熟练"）。"对的不知道为什么对、错的不知道为什么错"=白刷。
 - 抓大放小："主要考点之外的细枝末节考法，正式考试很难遇到，平时遇到做错了基础就好。"
- **100-129**（"很有希望达到140的群体"）：目标="**扣分只在写作**"。
 - ①不纠结介词代词冠词——"做对了就赚了，做错了无所谓"；"2021年语法填空冠词几乎没考、完形没考介词"；"你最后拼的是总分，纠结它第一耽误时间，第二打乱错题分析节奏，第三扰乱情绪。放弃，不要管。"
 - ②客观题**限时训练**（底线，超时=该题失败）：阅读 A+B 两篇（应用文+记叙文）合计≤12分钟；C+D（说明文+议论文）合计≤18分钟；七选五一篇≤10分钟；语法填空≤10分钟；完形一篇 10~15 分钟。"速度的提高背后是熟练度和习惯，平时不计时，考场上就没有时间把握——客观题不快，写作就没时间构思打草稿。"
 - ③**错题数量目标**：语法填空的时态/非谓语/从句不许错；词性变换、单复数、比较级最高级不许错（送分题，考基本功）；完形名/形/副三大类不许错（约占完形一半），动词题≤2道；阅读应用文+记叙文（7题14分）一分不丢；说明文+议论文合计错≤2道（每篇≤1道）；七选五5题错≤1道（"纯看方法和思路，靠翻译做题恐怕要完"）。

## 讲规划时的口吻

- 先问档位再给方案（你现在多少分 → 三件事里先干哪件）。
- 时间线说得斩钉截铁，带截止日期和后果（"春季还在看单词，及不了格，建议你去看其他科目"）。
- 反对无效努力："到了高三还在聊3500、要不要看课本单词，这都是非常低效的方法。"
- 比喻贴身："解题是命题的反操作——我命题时给你系了个结，你解题没剪刀也不能看结怎么打的，你知道那个劲儿怎么打的，就知道怎么解开它。"
